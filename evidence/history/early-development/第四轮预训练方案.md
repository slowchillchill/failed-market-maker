# M3 第四轮超参数搜索方案

基于三轮 30 组实验的深度统计分析，本轮转变思路：**从寻找更好的超参数，转向降低训练方差和探索全新训练范式**。

## 一、三轮实验的深层分析

### 1.1 30 组实验统计概况

| 指标 | 均值 | 标准差 | 最小 | 最大 |
|------|------|--------|------|------|
| top_decile_mean_ev_up | +0.339 | 0.094 | +0.100 | +0.547 |
| ev_up_sign_acc | 0.596 | 0.034 | 0.523 | 0.654 |
| AUC | 0.702 | 0.045 | 0.594 | 0.794 |
| ECE | 0.257 | 0.062 | 0.100 | 0.352 |
| ev_rank_corr | 0.030 | 0.032 | -0.052 | 0.097 |
| best_epoch | 7.4 | 7.4 | 1 | 35 |

### 1.2 指标间相关性的重大发现

| 指标对 | 相关系数 | 含义 |
|--------|---------|------|
| AUC ↔ ECE | **r=-0.80** | 强负相关：分类好 = 校准好 |
| AUC ↔ rank_corr | **r=+0.80** | 强正相关：分类好 = 排序好 |
| ECE ↔ rank_corr | **r=-0.81** | 强负相关：校准好 = 排序好 |
| **top10_ev ↔ AUC** | **r=-0.09** | **几乎无关！** |
| **top10_ev ↔ ECE** | **r=+0.11** | **几乎无关！** |
| top10_ev ↔ sign_acc | r=+0.46 | 中等正相关 |

**核心洞察**：top10_ev 和 AUC/ECE/rank_corr 度量的是**两个几乎正交的维度**：
- **维度 A（top10_ev / sign_acc）**：模型在极端预测上能否赚钱——"赌得准不准"
- **维度 B（AUC / ECE / rank_corr）**：模型在全样本上分类和校准的质量——"排得准不准"

优化一个维度不帮助另一个维度。前三轮我们主要在维度 A 上搜索（top10_ev 为选模标准），导致选出的模型在维度 B 上并不突出。

### 1.3 方差才是最大的敌人

| 证据 | 细节 |
|------|------|
| R04 vs T04（完全相同参数） | top10_ev: +0.547 vs +0.380，差距 0.167 |
| top10_ev 标准差 | 0.094（30 组），但同参数方差 ~0.17 |
| best_epoch 变异系数 | std/mean = 100%（极不稳定） |
| 最优 train_loss 区间 | 0.3~1.5，但最优实验分散在 0.23~1.74 |

**结论**：在当前的单次训练评估下，我们无法可靠区分 top10_ev +0.35 和 +0.50 的配置——后者可能只是运气好。任何进一步的超参数搜索在解决方差问题之前都是低效的。

### 1.4 还没尝试过什么

| 方向 | 状态 |
|------|------|
| 确定性训练（固定种子） | ❌ 从未使用，结果不可复现 |
| EMA（指数移动平均权重） | ❌ 最成熟的方差降低技术 |
| 数据增强（特征噪声） | ❌ 最简单的正则化 |
| Focal Loss（难例聚焦） | ❌ 分类领域的标准改进 |
| Snapshot Ensemble（快照集成）| ❌ 单次训练即可获得集成效果 |
| R-Drop（正则化 Dropout） | ❌ 通过双前向传播进行正则化 |
| 多种子集成 | ❌ 最可靠的性能提升手段 |

## 二、第四轮设计思路

### 2.1 核心策略转变

> **从"寻找更好的参数"转向"让好的参数可靠地产生好的结果"。**

本轮的首要目标不是刷新 top10_ev 最高分，而是：
1. **建立可靠的评估基线**（多种子，减少运气成分）
2. **用 EMA 降低单次训练的方差**（已在 CV/NLP 中被广泛验证）
3. **大胆尝试全新训练范式**（特征增强、Focal Loss、Snapshot Ensemble）

### 2.2 固定的基础配置

基于三轮经验，以下参数不再搜索：

```
seq_len=100, d_model=128, n_transformer_layers=2, nhead=4,
batch_size=2048, lr=4e-4, ev_loss_fn=huber, epochs=30, patience=5
```

选择 Huber（而非 MSE）作为默认 EV 损失，因为 Round 3 确认它不损失性能且改善 sign_acc。

### 2.3 需要的代码修改

| 改动 | 文件 | 改动量 | 说明 |
|------|------|--------|------|
| `--seed` | train.py | ~8 行 | 固定 torch/numpy/random 种子，确保可复现 |
| `--ema-decay` | train.py | ~30 行 | 维护 EMA 权重副本，val/test 使用 EMA 模型 |
| `--feature-noise` | train.py | ~5 行 | 训练时向归一化后的特征添加高斯噪声 |
| `--focal-gamma` | loss.py | ~15 行 | Focal Loss 替代 CrossEntropy |
| `--snapshot-ensemble` | train.py | ~20 行 | 保存多个检查点，测试时平均预测 |

## 三、5 项代码修改详情

### 3.1 确定性种子 (`--seed`)

```python
# train.py main() 开头
if args.seed is not None:
    import random
    random.seed(args.seed)
    np.random.seed(args.seed)
    torch.manual_seed(args.seed)
    torch.cuda.manual_seed_all(args.seed)
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
    print(f"[train] deterministic mode: seed={args.seed}")
```

### 3.2 EMA 权重 (`--ema-decay`)

EMA 维护模型参数的指数移动平均：`θ_ema = decay × θ_ema + (1 - decay) × θ_model`。

EMA 模型更稳定，因为它"记住"了训练过程中多个时间点的参数，而非只用最后一个。在 CV（Stable Diffusion, EfficientNet）和 NLP（BERT 微调）中广泛使用。

```python
# train.py — EMA 类
class ModelEMA:
    """Exponential Moving Average of model weights."""
    def __init__(self, model, decay=0.999):
        self.decay = decay
        self.shadow = {k: v.clone().detach() for k, v in model.state_dict().items()}

    @torch.no_grad()
    def update(self, model):
        for k, v in model.state_dict().items():
            self.shadow[k].mul_(self.decay).add_(v, alpha=1 - self.decay)

    def apply(self, model):
        """Load EMA weights into model (for eval). Returns backup for restore."""
        backup = {k: v.clone() for k, v in model.state_dict().items()}
        model.load_state_dict(self.shadow)
        return backup

    def restore(self, model, backup):
        model.load_state_dict(backup)
```

训练循环中：
```python
# 每个 epoch 后
if ema is not None:
    ema.update(unwrapped_model)
    backup = ema.apply(unwrapped_model)  # EMA 权重用于 val
    val_metrics = eval_epoch(...)
    ema.restore(unwrapped_model, backup)  # 恢复训练权重
```

### 3.3 特征噪声增强 (`--feature-noise`)

在训练时向归一化后的输入添加高斯噪声。这是最简单的数据增强形式，迫使模型学习对小扰动鲁棒的特征。

```python
# train_epoch 中，obs 已送到 device 后：
if feature_noise > 0 and model.training:
    obs = obs + torch.randn_like(obs) * feature_noise
```

注意：噪声是加到**归一化后**的特征上。σ=0.1 意味着添加约 0.1 个标准差的噪声。

### 3.4 Focal Loss (`--focal-gamma`)

标准 CrossEntropy 对所有样本一视同仁。Focal Loss 给"已经分对的简单样本"更低的权重，让模型集中学习困难样本：

`FL(p_t) = -(1 - p_t)^γ × log(p_t)`

当 γ=0 退化为标准 CE；γ=2 是常用值（来自 RetinaNet 论文）。

```python
# loss.py
def focal_loss(logits, targets, gamma=2.0, label_smoothing=0.0):
    """Focal Loss with optional label smoothing."""
    ce = nn.functional.cross_entropy(logits, targets, reduction='none',
                                      label_smoothing=label_smoothing)
    p_t = torch.exp(-ce)  # p_t = probability of correct class
    focal = ((1 - p_t) ** gamma) * ce
    return focal.mean()
```

### 3.5 Snapshot Ensemble (`--snapshot-ensemble`)

训练过程中每隔 N 个 epoch 保存一次 checkpoint，最终测试时加载所有快照、对预测取平均。这样单次训练就能获得类似集成的效果。

```python
# 每个 epoch 后，如果是指定的保存点
if snapshot_ensemble and epoch in snapshot_epochs:
    snap_path = out_dir / f"snapshot_ep{epoch}.pt"
    torch.save(model.state_dict(), snap_path)
    snapshots.append(snap_path)

# 测试时
if snapshots:
    all_preds = []
    for snap_path in snapshots:
        model.load_state_dict(torch.load(snap_path))
        preds = eval_epoch(model, test_loader, ...)
        all_preds.append(preds)
    final_preds = average(all_preds)
```

### 设计逻辑

**A 组：多种子基线 + EMA（U01-U06）**

这是本轮最关键的 6 个实验。

U01-U03 使用 3 个不同种子但完全相同的配置，测量 top10_ev 的真实方差。如果 3 个结果是 +0.38, +0.35, +0.42，则方差约 0.035（std）——远小于 R04 vs T04 暗示的 0.17。之前 R04/T04 的差距可能是 **torch.compile 的非确定性**造成的（Round 4 固定种子 + cudnn.deterministic 可以消除这个因素）。

U04-U06 在完全相同的 3 个种子上加入 EMA decay=0.999。通过 `mean(U04-U06) - mean(U01-U03)` 可以精确测量 EMA 的效果，且统计可靠。

为什么 EMA 可能特别有效：
- 当前模型 best_epoch ≈ 5，之后快速过拟合。EMA 模型"记住"了 ep1-5 的参数混合，相当于隐式集成了不同训练阶段。
- EMA 不增加训练时间，不需要修改模型结构，开销几乎为零。
- 在 ImageNet 训练中，EMA 通常提升 0.5-1.0% accuracy。在我们方差更大的场景中可能效果更显著。

**B 组：大胆新技术（U07-U10）**

全部基于 EMA + seed=42，这样可以与 U04 直接比较。

- **U07（特征噪声 σ=0.1）**：训练时在归一化后的特征上加 N(0, 0.1) 噪声。这相当于告诉模型"这些特征值可能不完全准确"，迫使它学习更鲁棒的模式。σ=0.1 是保守选择（1/10 标准差），不会破坏信号但足以形成正则化。

- **U08（Focal Loss γ=2）**：30 组实验中，D1-D4（模型最不确定的区间）平均 edge=-0.103，D8-D10 平均 edge=+0.319。模型在"确信"的样本上赚钱，在"不确信"的样本上亏钱。Focal Loss 让模型花更多精力在困难样本上，可能改善中间 decile 的 edge（D5-D7 目前仅 +0.082）。

- **U09（Snapshot Ensemble）**：在 epoch 3, 5, 7 保存快照，测试时取 3 个快照预测的平均。不使用早停（patience=20），让训练跑满 20 epoch 以确保 3 个快照都生成。这相当于用一次训练获得 3 个模型的集成效果。

- **U10（终极组合）**：EMA + 轻度特征噪声（0.05，比 U07 更温和）+ label_smoothing=0.05（R3 验证轻度有效）。这是所有已确认有效或有理由相信有效的技术的组合。
