# 训练指标说明

Phase 1 监督预训练中使用的所有指标及其含义。

---

## 损失函数

### train_loss / val_loss

训练/验证集上的联合损失，计算公式：

```
total = lambda_cls × CrossEntropyLoss(logits, y_cls) + lambda_ev × MSELoss(ev_pred, y_ev)
       = 1.0 × 分类损失 + 0.5 × EV回归损失
```

**解读原则：**

- `train_loss` 衡量模型在训练集上的拟合程度，越低说明拟合越紧。
- `val_loss` 衡量模型在未参与训练的验证集上的表现，越低说明泛化越好。
- **train/val gap = val_loss - train_loss**：直接量化过拟合程度。gap 越大说明模型在学习训练集特有的噪声而非真实规律。

**注意：** `train_loss` 低不等于好。若 `train_loss` 快速下降而 `val_loss` 同步上升，是过拟合的典型信号。

## 方向分类指标（理智检查）

### val_auc（ROC-AUC）

> 目标：> 0.52（随机基线 0.50）

衡量模型**对 Up/Down 的排序能力**：随机从"Up最终赢"和"Down最终赢"的样本各取一个，模型给 Up 样本更高概率的概率。

```
AUC = P(P_up(Up样本) > P_up(Down样本))
```

- AUC = 0.50：等同于随机猜测
- AUC = 1.00：完美排序
- AUC = 0.75：任意配对时有 75% 的概率给出正确排序

**特点：** 对概率的绝对值不敏感，只看排序。即使模型输出的概率未精确校准，AUC 也可能很高。因此 AUC 是必要的理智检查，但不是盈利的充分条件。

### val_brier（Brier Score）

> 目标：< 0.25（随机基线 0.25）

衡量预测概率和真实结果之间的**均方误差**：

```
Brier = mean( (P_up - y_cls)² )
```

- 随机预测（P_up 恒等于 0.5）：Brier = 0.25
- 完美预测：Brier = 0.00

**特点：** 同时惩罚"方向错误"和"过于自信"。若模型频繁以高置信度给出错误预测（过拟合的典型表现），Brier 会显著恶化。

### ece（Expected Calibration Error）

> 目标：< 0.05

将预测概率划分为 10 个区间（0~0.1, 0.1~0.2, ...），计算每个区间内预测置信度与真实正例率之间的加权偏差：

```
ECE = Σ (区间样本量/总样本量) × |区间平均置信度 - 区间实际正例率|
```

ECE 越低，说明模型输出的概率越接近真实概率（校准越好）。例如 ECE=0.18 意味着：当模型说"有 70% 概率 Up 赢"时，实际上可能只有 52% 的概率——概率数值不可信。

## EV 预测质量

### ev_up_mae / ev_down_mae

预测 EV 与真实 EV 之间的平均绝对误差（仅计算 y_ev_mask 有效的样本）：

```
ev_up_mae = mean( |ev_up_pred - y_ev_up| )
```

单位与 y_ev 相同（归一化后的 USDC 收益）。用于诊断回归头的绝对精度。

### ev_rank_corr（Spearman 排序相关）

> 目标：> 0.03

衡量模型预测的 EV 与真实 EV 之间的**排序一致性**（Spearman ρ）：

```
ev_rank_corr = Spearman(ev_up_pred[mask], y_ev_up[mask])
```

- ρ = 0：预测排序与真实排序完全无关
- ρ = 1：排序完全一致
- ρ > 0.03：模型对 EV 有微弱但有意义的排序能力

这个指标比 MAE 更重要：即使 EV 的绝对值预测不准，只要排序对了，模型仍然能正确判断"哪些时刻更值得交易"。

## 直接盈利代理指标（主判据）

### ev_up_sign_acc（EV 符号准确率）

> 目标：> 0.52（随机基线 0.50）

对于每个"此刻是否应该买 Up"的决策，计算模型判断正确的比例：

```
ev_up_sign_acc = P( sign(ev_up_pred) > 0 == sign(y_ev_up) > 0  |  y_ev_mask 有效 )
```

通俗理解：**模型判断"这笔交易扣完手续费后赚还是亏"的准确率**。随机猜测基线约 50%。

这是最直接的盈利代理：如果模型能稳定超过 52%，说明它在识别"值得 taker 买入的时机"上有真实的信息优势。

### top_decile_mean_ev_up（前十分位条件均值 EV）

> 目标：> 0（Phase 1 必须通过的主判据）

计算步骤：
1. 将所有 val/test 样本按模型输出的 P_up 从高到低排序
2. 取前 10%（模型最自信认为应该买 Up 的时刻）
3. 计算这些时刻的真实 `y_ev_up` 均值

```
top_decile_mean_ev_up = mean( y_ev_up[P_up 前10%] )
```

**为什么这是主判据：** `y_ev` 标签已经包含了 taker 手续费（峰值约 1.80% @ p=0.50）。`top_decile_mean_ev_up > 0` 直接意味着：当模型最有把握时，执行 buy_up 市价单的期望收益在扣费后仍为正。这是 Phase 1 能否转化为真实盈利的直接验证。

### ev_up_conditional_mean_by_threshold

按不同的 P_up 阈值过滤样本，计算各阈值下有效样本的 `mean(y_ev_up)`：

```python
{
  "0.50": mean(y_ev_up | P_up > 0.50),  # 所有认为 Up 概率更大的样本
  "0.52": mean(y_ev_up | P_up > 0.52),
  "0.55": mean(y_ev_up | P_up > 0.55),
  "0.60": mean(y_ev_up | P_up > 0.60),
  "0.65": mean(y_ev_up | P_up > 0.65),
}
```

同时记录各阈值下的 `opportunity_rate`（符合条件的样本占比）。用于评估：当模型输出不同置信度时，实际盈利能力和交易频率的权衡。

### edge_by_decile

将所有样本按 P_up 从低到高分成 10 个等分位，计算每个分位内的 `mean(y_ev_up)`：

```
decile 1（P_up 最低10%）→ ... → decile 10（P_up 最高10%）
```

**理想形态：** 单调递增，且 decile 10 明显为正，decile 1 明显为负。单调性说明模型的置信度与实际 EV 方向一致，高置信度预测确实对应更高的实际 EV。

---

## 指标优先级汇总

| 优先级 | 指标 | 目标 | 用途 |
|-------|------|------|------|
| 主判据 | top_decile_mean_ev_up | > 0 | Phase 1 验收门槛 |
| 主判据 | ev_up_sign_acc | > 0.52 | Phase 1 验收门槛 |
| 理智检查 | AUC | > 0.52 | 确认不逊于随机 |
| 理智检查 | Brier | < 0.25 | 概率估计有意义 |
| 理智检查 | ECE | < 0.05 | 概率校准 |
| 排序能力 | ev_rank_corr | > 0.03 | EV 排序正确 |
| 诊断 | train/val gap | 越小越好 | 过拟合程度 |
| 诊断 | edge_by_decile | 单调递增 | 模型置信度与EV一致性 |

---

## 过拟合的典型信号

以下现象同时出现时，说明模型在记忆训练集噪声而非学习真实规律：

- `train_loss` 持续快速下降，`val_loss` 持续上升
- `val_auc` 和 `val_brier` 在初始几个 epoch 后开始退步
- `top_decile_mean_ev_up` 第 1 epoch 虚高，随后持续下跌
- train/val gap 随 epoch 增大

**应对方法：** 增大 dropout（0.1 → 0.2）、降低 LR（4e-4 → 1e-4）、启用早停（patience=5~8）。
