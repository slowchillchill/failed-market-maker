## 7. Findings

1. EMA 是本轮最稳定有效的 backbone 改动，B1/B2 相对 no-EMA A6 显著提升 val PnL 与 rolling stability。
2. Snapshot save 本身是 no-op。B8 与 B1 指标完全相同，不代表 snapshot ensemble 收益。
3. Focal / Label smoothing 在本轮口径下没有形成候选级收益。
4. BC agent route 没能挑战 backbone signal route；full_policy top-1 test FAIL。
5. IQL warm-start 能缓解 Hold collapse，但不是性能成功。
6. IQL native execution heads 不可靠；IQL-1 / IQL-2 native val 均约 -52。
7. IQL-2 fixed-route val 指标好但 collapsed，不能作为候选。
8. BC-3 oracle C quantile route 在 v7expanded 上 no-op，oracle 维度本轮未被有效测试。
